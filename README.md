# Basic Pong

A small, dependency-free recreation of Pong built with HTML, CSS, and
JavaScript.

## Run locally

Install dependencies once:

```bash
npm install
```

Start the preview server:

```bash
npm run dev
```

Then visit <http://localhost:3000>.

## Controls

- `W` / `S` or `Up` / `Down`: move the player paddle
- `Space`: start, pause, and resume
- `R`: restart the match

First to seven points wins.
