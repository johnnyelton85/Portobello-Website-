# Basic Pong

A small, dependency-free recreation of Pong built with HTML, CSS, and
JavaScript.

## Run locally

Open `index.html` in a browser, or serve the directory with any static file
server.

For example:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Controls

- `W` / `S` or `Up` / `Down`: move the player paddle
- `Space`: start, pause, and resume
- `R`: restart the match

First to seven points wins.
